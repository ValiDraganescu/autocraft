# Prompt template log

`sheet-rules.txt` is the prompt template: the rules every turnaround painting follows. `model.sh prompt <unit>` puts it in front of the unit's `look.txt` and saves the result as `<unit>/prompt.txt` and the template's version as `<unit>/prompt.version`.

## Changing the template

1. Raise the version in the first line of `sheet-rules.txt` (`# sheet-rules vN (date): what changed`).
2. Add a row to **Versions** below: what changed and which failure it answers.
3. Keep the old text in the **Versions** row (or its git history) so a result can be traced to the words that made it.

Change one thing at a time when you can: a sheet that got worse after two changes doesn't say which one did it. Ask the image AI for what to paint, not only for what to leave out: a list of don'ts (v2) gets the don'ts and a blander picture, and naming what you don't want ("not a toy, not plastic", v3) draws it. Say the look you want in positive words, and when a sheet has the look, crop a panel of it as the unit's `style.jpg` and attach it: a picture says a style better than any list.

Before logging, check the file is the new painting: Grok's downloads get random names (`UxZKv.jpg`, `2gape.jpg`), and once the old v1 file was sent back as a v3 result. `cmp` it against the kept versions and check its pose against the current `stencil.png`.

## Logging a painting

After every `model.sh split`, add a row to **Results**, even for a painting that was thrown away. The numbers come from split's output; the problems from looking at `painted.*` and `compare.png`.

- **stretch**: the fitted x/y scale, painted size over stencil size (1.08 = 8% bigger).
- **IoU**: the fitted overlap per orthographic view, front / right / back / left / top.
- **spread**: the largest disagreement between views on width, depth or height.
- **baked light**: highlights, reflections, shading or shadows painted into the sheet (none / slight / strong, and where).
- **problems**: shapes that changed, details missing or different between views, anything that made a re-roll necessary.
